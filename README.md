# Python Study

A beginner-friendly collection of Python practice examples covering basic programming and object-oriented programming.

## Files

- [`python.py`](python.py) contains examples for input and type conversion, loops, functions, lists, dictionaries, exception handling, and a simple inventory lookup. Most examples are commented out; the active example demonstrates a `Song` class and creates two song objects.
- [`lesson01.py`](lesson01.py) contains commented practice examples that build up to classes and objects, student records, methods, conditions, loops, and a menu-driven student lookup.

## Run an example

Run the active example in `python.py` with Python 3:

```bash
python3 python.py
```

To try a commented exercise, remove the leading `#` from that example and run the file again. In `lesson01.py`, all examples are currently commented out, so uncomment the example you want to study before running it:

```bash
python3 lesson01.py
```

## Suggested study order

1. In `python.py`, start with input and type conversion, then try the sum loop and even-or-odd function.
2. Continue with lists and dictionaries, then practice handling invalid input with `try`/`except`.
3. In `lesson01.py`, follow the `Student` examples to learn how constructors, attributes, and methods work.
4. Try the student list, pass/fail check, and menu examples; finish with the active `Song` class example in `python.py`.
